# Aiti Guru

Тестовый React-проект с авторизацией и страницей товаров.

## Стек

- React 19
- TypeScript
- Vite
- React Router 7
- TanStack Query
- Zustand
- Tailwind CSS 4
- shadcn-style UI components

## Основной функционал

- login / register
- protected route для страницы товаров
- загрузка товаров с DummyJSON API
- сортировка товаров
- серверный поиск с debounce `100ms`
- серверная пагинация с хранением страницы в URL
- выбор строк и просмотр деталей товара

## Запуск

```bash
yarn
yarn dev
```

## Сборка

```bash
yarn build
```
